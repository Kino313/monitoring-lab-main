# CyberLab Monitoring Demo - Change Summary

## Purpose

This project is a local monitoring demo for the CyberLab monitoring task.

The goal is to show CyberLab-related Bank and Hospital targets in a Grafana dashboard and display whether each target is `UP` or `DOWN`.

The monitoring flow is:

```text
Bank/Hospital target
-> Blackbox Exporter checks reachability
-> Prometheus stores the result
-> Grafana displays the status
```

## Current Status

The local monitoring stack is configured and can run with Docker Compose.

Grafana automatically loads:

- a Prometheus datasource
- a CyberLab dashboard

The dashboard currently shows Bank and Hospital logical nodes.

Important note:

The current target URLs are local demo placeholders. They are not real CyberLab IP addresses yet. To monitor the real CyberLab environment, replace the placeholder URLs in `targets.yml` with real CyberLab IPs, domains, or service URLs.

- local handoff notes

Purpose:

To keep the package clean, portable, and free from local machine information.

## Why `data/` Is Not Included

The `data/` folder is generated by Prometheus while the project is running.

It contains local runtime monitoring data, not source code or required configuration.

The project can run without it. Prometheus will create new runtime data automatically after:

```powershell
docker compose up -d
```

## How To Run

From the project folder, run:

```powershell
docker compose up -d
```

Then open Grafana:

```text
http://localhost:3300
```

Login:

```text
Username: admin
Password: admin
```

Open the dashboard:

```text
http://localhost:3300/d/cyberlab-blackbox/cyberlab
```
